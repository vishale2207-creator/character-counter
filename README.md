# Character Counter – Real-Time Text Analyzer

The Character Counter is a simple and interactive web application that helps users track the number of characters in a message in real time.

This project is built using HTML, CSS, and JavaScript with a clean user interface and responsive design. It allows users to type a message while automatically updating the total character count and the number of remaining characters.

### Project Links

**Live Website:** [https://vishale2207-creator.github.io/character-counter/]

**GitHub Repository:** [https://github.com/vishale2207-creator/character-counter/tree/main]


### Features
- Real-time character counting
- Maximum character limit of 200
- Remaining character display
- Dynamic progress bar
- Warning message when approaching or reaching the character limit
- Responsive design for desktop and mobile devices

### Technologies Used
- HTML5
- CSS3
- JavaScript

This project helped me practise JavaScript event listeners, DOM manipulation, conditional statements, and dynamic UI updates.
